# SkyFlow: Air Traffic Control & Airport Network

## Project Structure
- `sql/`: SQL DDL scripts, seed data, and analytical queries.
  - `schema_shared.sql`: Shared master schema for all 3 members.
  - `seed_member1.sql`: M1 ground infrastructure seed data.
- `pages/`: Streamlit multipage application.
  - `1_Airport_Ground_Control.py`: M1 ground control UI.
- `app.py`: Streamlit entry point.
- `docs/`: ER diagrams, normalization notes, and project report.
